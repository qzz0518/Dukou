D Dukou

Dukou.

批量转发微信消息给任意 Agent，也可以保存为本地离线备份。Dukou 使用微信原生转发与导出，不读取数据库、不解密、不注入。

macOS 14 或更高版本。

获取 Dukou

  • 下载最新版
  • 使用 Homebrew：brew install --cask qzz0518/tap/dukou
  • 查看版本历史
  • 在 GitHub 查看源码
  • 报告问题
Dukou on GitHub

Native, local, and made for macOS.

功能概览

  • 微信原生转发
  • 批量发送给 Agent
  • 本地离线备份
  • 仅更新检查联网
